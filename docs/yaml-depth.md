This ticket expands reference/task depth, not the lesson count.

Deterministic evidence: all 60 exact documents pass parser/schema checks, happy/edge/rejection/recovery assertions; all 39 topics have registered situational evidence. The common audit should have no YAML findings. The concurrency examples use the default single-pending policy; the newer GitHub `queue: max` feature is documented as outside this fixture scope. A schema validator is not a language compiler; no static type-check or running-service evidence is claimed. Historical findings for other languages stay visible.

actionlint checks workflows and reads local action metadata to check caller contracts. It does not fully validate composite action bodies; the checker additionally projects the exact parsed `runs.steps`/output expressions into a typed workflow-dispatch fixture and verifies their references, and asserts required metadata/shell fields directly. Expressions, secrets, shell commands, concurrency scheduling and actual runner outputs are **not evaluated**. These are offline contract assertions.

cfn-lint checks resource schemas/intrinsic shapes and references without resolving a real stack, parameter-dependent remote values, IAM, or resource existence. Some output-property diagnostics are E6101 and an out-of-range parameter default produces W1030; both yield failing lint results in this pinned tool. Compose config parses its consumer-specific !reset/!override tags and normalizes layered/profile/interpolated models; it does not validate Dockerfile execution, container health, startup success or image existence. Generic safe YAML loading rejects Compose-specific tags; do not assume Compose rejects every unknown application tag.
