03 / Local operation

No cloud or AI required.

Syntaxiser reads curated examples and references bundled with the extension. Context detection, search, pins, and lesson tracking run locally. No account, API key, cloud service, or AI model is required.

Browse core language topics and supported libraries, from Rust’s Tokio and Serde to TypeScript’s React and Zod. Coverage varies by language.

04 / Installation

Install the extension
from source.

You’ll need Git, VS Code 1.93+, nvm, and pnpm. The repository’s .nvmrc selects the Node version.

Open the repository ↗

Build the extension

git clone https://github.com/sbracegirdle/syntaxiser.git
cd syntaxiser
nvm install
nvm use
pnpm install
pnpm package
  1. In VS Code, run Extensions: Install from VSIX… and choose the generated syntaxiser-*.vsix.
  2. Open a supported file and run Syntaxiser: Open Reference.
  3. Move your cursor, search for a task, or browse the Reference tab.

05 / Common questions

Usage and limitations.

Does Syntaxiser write code for me?

It shows curated reference material beside your code. You choose what to use. Some examples are fragments that need surrounding code, imports, or dependencies; read the explanation before adapting them.

Are there lessons for every language?

Built-in lesson coverage varies. You can create your own lessons and track them separately for each supported language. Check the repository for current built-in tracks.

What happens without an internet connection?

The extension’s context suggestions, search, references, pins, and lesson tracking run locally. Opening learning-source links, installing dependencies, and some examples’ external services need a connection.

Can I contribute an example or report a problem?

Yes. Open an issue on GitHub or read the developer guide to learn about catalogs and validation.
